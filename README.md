## 🎯 Why Hybrid RAG?
- **Dense Vector Search (Cosine Similarity)**: Captures conceptual relevance and paraphrasing.
- **Sparse BM25 Search**: Matches exact keywords, SKUs, serial numbers, and acronyms.
- **Reciprocal Rank Fusion (RRF)**: Merges both ranking lists into an optimal blended context window.
